# calculator
help - для справки
        Операторы:  + - * / % ^ !   (скобки, унарный минус)
        Функции:    sin cos tan asin acos atan atan2 sinh cosh tanh
                    ln log log2 exp sqrt cbrt pow hypot
                    abs floor ceil round trunc sign min max deg rad
        Константы:  pi, e
        Переменные: x = 2 + 3      (ans — результат предыдущего выражения)
        Команды:
          help            эта справка
          mode deg|rad    режим углов
          history         история вычислений
          vars            список переменных
          mem             показать память
          m+ <expr>       прибавить к памяти
          m- <expr>       вычесть из памяти
          mc              очистить память
          exit / quit     выход
