# hangman_game
Игра "Виселица" для семестрового задания

Система загадывает слово которое необходимо угадать указывая буквы которые могут подходить слову, за каждую ошибку дорисовывается изображение "Человека на Виселеце", всего можно допустить 6 ошибок при достижении которых будет конец игры.

Запуск программы hgmgame.cpp, выход из неё происходит после нажатия "н" в выборе "попробовать ещё раз" или принудительно закрыв консоль вывода программы
